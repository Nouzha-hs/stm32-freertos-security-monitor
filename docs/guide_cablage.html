Guide Visuel de Câblage : Buzzer ➔ STM32 NUCLEO-F401RE

Pas de panique pour la carte : les 3 fils transportent une tension très faible et inoffensive (5V/3.3V).
Munissez-vous de vos 3 câbles Dupont Mâle-Femelle (Violet, Bleu, Vert).
• Côté Femelle (trous) : emboîtez-le sur les 3 broches du Buzzer.
• Côté Mâle (tiges métalliques) : enfoncez-le dans les trous indiqués de la Nucleo.
